# Linkflow - 요구사항 문서

> 링크를 저장하고, 개인 프로필이나 가이드로 만들어 공유하는 북마크 매니저

---

## 핵심 컨셉

단순 북마크 저장를 넘어 **"링크 묶음 → 스토리가 있는 페이지 → URL 하나로 공유"**
링크 + 텍스트 + 이미지를 섞어서 개인 프로필, 절차서, 가이드 등 다양한 형태로 만들고 공유할 수 있다.

---

## 용어 정의

| 용어 | 설명 |
|------|------|=
| **그룹** | 개인 북마크 관리용 묶음. 빠른 접근 목적, 나만 보는 것 (Toby 스타일) |
| **컬렉션** | 공유용 페이지. 설명/순서/템플릿이 있고 외부에 URL로 공유 가능 |
| **인박스** | 분류 전 임시 보관소 |

---

## 계정 및 데이터 저장

- 모든 데이터는 **계정 기반**으로 저장 및 관리
- 회원가입 / 로그인 필수 (이메일 + 비밀번호)
- 사용자별로 인박스, 그룹, 컬렉션, 태그 등 모든 데이터가 격리됨
- 로그인 시 어떤 기기에서든 동일한 데이터에 접근 가능 (크로스 디바이스 동기화)
- Chrome Extension도 로그인 후 사용 가능

---

## 기능 목록

### 1. 북마크 저장

- URL 붙여넣기 시 자동으로 제목/설명/썸네일 fetch
- 저장 즉시 인박스로 이동
- 태그 추가 가능

### 2. 인박스

- 분류되지 않은 링크 임시 보관소
- "저장 → 나중에 그룹/컬렉션으로 분류" 흐름 지원
- 인박스 아이템: 읽음 처리 / 그룹으로 이동 / 컬렉션으로 이동 / 삭제

### 3. 그룹

- 북마크를 빠르게 묶는 단위 (이름 + 이모지)
- 개인 대시보드에서만 보임 (비공개)
- Toby처럼 컬럼 형태로 표시
- 그룹에서 링크를 선택해 컬렉션으로 변환 가능

### 4. 컬렉션

- 공유를 위한 페이지 단위 (이름 + 이모지 + 설명)
- 안에 추가할 수 있는 블록 타입:
  - **링크 블록**: URL + 설명 + 태그
  - **텍스트 블록**: 마크다운 간단 메모
  - **이미지 블록**: 이미지 업로드 또는 URL
- 블록 순서 드래그 앤 드롭으로 변경
- 공유 ON/OFF 토글
- 공개 URL 생성 (예: `/c/abc123_`)
- 공유 페이지 템플릿 선택:
  - **가이드 모드**: 순서 있는 절차서 형태
  - **프로필 모드**: 개인 소개 + 링크 나열 형태

### 5. 빠른 검색

- 제목 / URL / 메모 전체 텍스트 검색
- 단축키 지원 (Cmd+K)

### 6. 링크 상태 체크

- 저장된 링크 주기적으로 유효성 확인 (404, 접근 불가 등)
- 죽은 링크 뱃지 표시

### 7. 북마크 Import

- 크롬 북마크 HTML 파일 업로드 → 자동 파싱 → 인박스로 일괄 추가

### 8. Chrome Extension

팝업 구성:
- **현재 페이지 저장**: 보고 있는 페이지들을 원하는 그룹으로 바로 저장
- **자동 추천**: 자주 방문하지만 미등록된 사이트 목록 (`chrome.topSites` API)
  - AI 기능 활용: 사용자가 직접 AI 토큰(API Key) 입력, 해당 토큰으로 호출
  - 원클릭 인박스 추가
- **최근 저장 목록**: 최근에 저장한 링크 빠르게 확인
